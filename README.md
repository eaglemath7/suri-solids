# 수리의 입체도형 연구소

회전체와 단면, 다섯 정다면체, 기둥·뿔·구의 부피와 겉넓이를 탐구하는 독수리 게임입니다.

- 회전체: https://eaglemath7.github.io/suri-solids/#revolve
- 정다면체: https://eaglemath7.github.io/suri-solids/#poly
- 부피·겉넓이: https://eaglemath7.github.io/suri-solids/#measure

검증: `node verify.cjs`

정다면체 다섯 종류를 모서리를 따라 접고 펼칠 수 있습니다. 펼친 전개도의 면 겹침, 면 크기 보존, 모서리 연결을 자동 검증합니다.

정십이면체는 가운데 오각형에 다섯 오각형이 붙은 꽃 두 개를 이어 놓은 전개도를 기본으로 제공합니다. 이어진 모양 전개도로 전환할 수도 있습니다.

정다면체 면의 기본 투명도는 50%이며, 0~80% 범위에서 조절할 수 있습니다.

정육면체 전개도 11개를 도형 위의 작은 그림으로 선택할 수 있습니다.
